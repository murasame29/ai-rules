# Architecture Decision Records (ADR)

このディレクトリには、プロジェクトの重要なアーキテクチャ決定を記録します。

---

## ADRとは

ADR (Architecture Decision Record) は、アーキテクチャに関する重要な決定とその理由を記録するドキュメントです。

---

## ファイル命名規則

```
NNN-title-with-dashes.md
```

例:
- `001-use-clean-architecture.md`
- `002-choose-postgresql.md`
- `003-adopt-jwt-authentication.md`

---

## テンプレート

```markdown
# ADR-NNN: タイトル

## Status
Proposed | Accepted | Deprecated | Superseded

## Context
決定が必要になった背景・状況

## Decision
何を決定したか

## Consequences
この決定による影響（良い点・悪い点）
```
